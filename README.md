## Funcionalidades
- **Ejercicio 1 (`Ejercicio1`):** Implementación de herencia múltiple mediante las interfaces `Hablador` y `Trabajador` en la clase `Persona`, ejecutando ambos contratos desde `PersonaPrueba`.
- **Ejercicio 2 (`Ejercicio2`):** Implementación de las interfaces `Volador` y `Nadador` en la clase `Animal`, validando múltiples comportamientos en `AnimalPrueba`.
- **Ejercicio 3 (`Ejercicio3`):** Demostración de errores de compilación por contratos incompletos y análisis de malas prácticas al implementar interfaces sin cohesión lógica (`Corredor`, `Arbol` y `UsoIncorrectoInterfacesPrueba`).
